# Basic Chatbot 🤖

A simple rule-based chatbot built using Python as part of the CodeAlpha Python Programming Internship.

## 📌 Features
- Responds to basic user inputs
- Interactive console-based conversation
- Handles multiple predefined commands
- Exit option using "bye"
- User-friendly chatbot responses

## 🛠 Technologies Used
- Python
- Loops
- Functions

## ▶ How to Run
1. Download or clone this repository
2. Open the project in VS Code
3. Run the following command in terminal:

python chatbot.py

## 💬 Supported Commands
- hello
- how are you
- what is your name
- bye

## 📷 Project Type
Console-based Python chatbot
